# Architecture Decision Records

Records of decisions with real trade-offs and a lasting rationale —
things worth explaining to someone reading this repo cold, not
retroactively obvious from the code. Most of this repo's "why" already
lives inline in each endpoint's `docs/*.md` Decisions section; an ADR is
for a decision that spans multiple endpoints or predates any single one
of them existing yet.
