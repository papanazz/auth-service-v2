# Auth Service

Production-grade authentication service built with Go.

## Features

- User registration
- Login
- JWT authentication
- Refresh token rotation
- Session management
- RBAC
- Audit logging
- HTTP API
- gRPC API
- OpenTelemetry observability

## Tech Stack

- Go
- PostgreSQL
- Redis
- Docker
- OpenTelemetry
- Prometheus
- Grafana

## Architecture

Clean Architecture with:

- Domain layer
- Application layer
- Infrastructure layer
- Delivery layer
